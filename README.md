# Adoteme — protótipo v2

Protótipo navegável da segunda versão do Adoteme, app que conecta pets resgatados a famílias que querem adotar.

**Abrir o protótipo:** https://jenichagas.github.io/adoteme-uiux-v2/

Esta versão aplica as melhorias de usabilidade encontradas no teste com usuários do Produto 2:

| # | Melhoria |
| --- | --- |
| M1 | Ver os pets sem fazer login; o login só aparece ao salvar, conversar ou adotar |
| M2 | Vacina, castração e idade no topo do perfil do pet |
| M3 | Formulário de adoção e confirmação com os próximos passos |
| M4 | Tudo em português, com texto maior e mais escuro |
| M5 | Botões com rótulo: Mensagem e Ligar |
| M6 | Abas sem a seta de voltar repetida |
| M7 | Conversas com nome do tutor, horário e mensagens não lidas |

No botão **Controles**, no canto da tela, a opção "Mostrar melhorias numeradas" marca cada mudança na tela.
